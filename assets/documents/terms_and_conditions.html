2. DESCRIPTION OF SERVICE

Cactus Alert is a mobile application that provides real-time information about emergency incidents and fire station locations in the Phoenix, Arizona metropolitan area. The App:

  • Displays incident data sourced from the Phoenix Fire Department's public API

  • Sends push notifications for selected emergency incidents
